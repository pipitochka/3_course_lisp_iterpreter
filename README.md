# MiniLisp

Интерпретатор Lisp на Java

## Возможности

- Поддержка **списков**, **строк**, **чисел** (int и float)
- Специальные формы:
    - `quote` — хранение значения без вычисления
    - `eval` — вычисление значения
    - `typeof` — определение типа объекта
    - `cons` — добавление элемента в список
    - `car` — получение головы списка
    - `cdr` — получение хвоста списка
    - `if` — условное выражение
    - `do` — последовательное вычисление нескольких выражений
    - `print` — вывод значения
    - `read` — чтение значения из консоли
    - `symbol` — создание символа из строки
    - `def` — определение символа
    - `set` — изменение значения существующего символа
- Бинарные операции: `+`, `-`, `*`, `/`, `%` 
- Бинарные предикаты: `<`, `>`, `==`, `!=`, `<=`, `>=`
- Обработка ошибок: незакрытые строки, незакрытые списки
- REPL команды:
    - `:q` / `:quit` / `:exit` — выход
    - `:l <filename>` / `:load <filename>` — загрузка и выполнение файла
    - `:` — повтор последней команды


## Использование

### Интерактивный режим

```bash
java -jar minilisp.jar
```

Комманды
 ```bash
:q // выход из файла
:l <filename> // загрузка и выполнение Lisp-файла
```   

### Не интерактивный режим

```bash
java -jar minilisp.jar --file myscript.lsp
```
